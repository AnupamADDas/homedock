Hardware Profile & Limitations

Platform: ASUS ZenBook 13 UX331UAL (Intel Core i7-8550U, Linux 7.0 generic, Ubuntu 24.04)

Sensors: CPU package and core temperatures obtained via standard Linux hwmon. Fan RPM read directly from ASUS WMI interface. If any sensor is disconnected or unsupported, it gracefully reports as unavailable without failing.

Security: Running under an unprivileged user process. SMART attributes require root device ioctls and are marked unavailable to preserve the principle of least privilege.
